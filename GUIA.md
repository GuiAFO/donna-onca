# Guia rápido — Donna Onça 💗

## Colocar o app na tela de início do iPhone (faz só uma vez)
1. Abra o link do app no **Safari**.
2. Toque no botão de **Compartilhar** (quadradinho com a setinha pra cima).
3. Escolha **"Adicionar à Tela de Início"** → **Adicionar**.
4. Pronto! Agora é só tocar no ícone **Donna Onça** como qualquer outro app.

## Cadastrar uma peça
1. Toque em **📷 Escanear código de barras** e aponte para o código da etiqueta.
   - Deu certo? O **Código** já aparece preenchido.
   - Não leu? Toque em **Digitar o código à mão** e escreva a referência.
2. Confira a **Descrição** (nome da peça, sem o tamanho). Pode **falar**: toque no 🎤 ou no
   microfone do teclado do iPhone.
3. Toque nos **Tamanhos** (P, M, G, GG…). Pode marcar vários de uma vez — cada um vira uma
   linha na planilha. Tem tamanho diferente? Escreva no campo "outro tamanho" e toque **Add**.
4. Confira o **Fornecedor** (já vem "Valentina Moda Intima"; dá pra trocar).
5. Digite **Valor custo** e **Valor venda**. (Se a peça já foi cadastrada antes, o app sugere
   os últimos valores.)
6. Toque em **Salvar na planilha**. 🎉

## Dicas
- Vai cadastrar várias peças do mesmo fornecedor? Depois de salvar, o fornecedor continua
  preenchido — é só escanear a próxima.
- Apareceu "Já cadastrado"? É só aviso: significa que esse código já existe (você está
  repondo). Pode salvar normalmente.
- Nada de foto é guardada: a câmera só lê o código na hora.
